Contract Manager

Interactive dashboard for contracts, milestones, expenses, and payments using fictional data.

Next.jsTypeScriptTailwind CSSRechartsRadix UI
PROJECT VIEW

A focused view of the problem, solution, and workflow.

Nº 05

CONTEXT

The context

This case presents a simplified version of a commercial contract management product. The demo uses fictional data only, with no login, database, or external integrations; changes stay in memory and reset when the page reloads.

PRODUCT SCOPE

What was built

  • 01Financial dashboard for contract values, expenses, and payments.
  • 02Contract details with companies, milestones, expenses, and history.
  • 03Interactive create, edit, and delete flows for contracts and expenses.
  • 04Milestone updates and payment completion actions.

IMPLEMENTATION

Contribution and decisions

  • Keep the product's main workflows in a focused, responsive interface.
  • Replace database and authentication with typed mock data and shared in-memory state.
  • Recalculate financial indicators from changes made in the demo.

SOLUTION LOGIC

Solution flow

  1. 01Financial dashboard→
  2. 02Open a contract→
  3. 03Update milestones and expenses→
  4. 04Review payments
LEARNING

A demo version can present real workflows without exposing documents, credentials, or client data.
