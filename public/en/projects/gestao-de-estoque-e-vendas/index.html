CASE 01Systems

Stock and sales management

Stock, sales, incoming payments, and cash operations in one operations panel.

Next.jsTypeScriptDrizzleLibSQL
PROJECT VIEW

A focused view of the problem, solution, and workflow.

Nº 01

CONTEXT

The context

When each movement is recorded in a different place, it is harder to understand the real state of an operation. This internal tool brings stock, sales, cash, commissions, and receivables together.

PRODUCT SCOPE

What was built

  • 01Product and stock movement tracking.
  • 02Sales, incoming payments, and cash operation records.
  • 03Commission and receivables overview.

IMPLEMENTATION

Contribution and decisions

  • Domain rules organized alongside the data flow.
  • Next.js and TypeScript for the application, with Drizzle ORM and LibSQL for persistence.
  • A panel designed for frequent lookup and day-to-day operations.

SOLUTION LOGIC

Solution flow

  1. 01Movement→
  2. 02Business rule→
  3. 03Related record→
  4. 04Cash overview
LEARNING

A clear history depends on treating each change as part of the same operation instead of an isolated row on a screen.
