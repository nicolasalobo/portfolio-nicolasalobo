CASE 04Automation

Python Tools Hub

A web hub that discovers Python scripts and presents them as tools.

PythonStreamlitPillowONNX Runtime
PROJECT VIEW

A focused view of the problem, solution, and workflow.

Nº 04

CONTEXT

The context

Small scripts are useful, but can be hard to discover and operate for people who do not code. The hub finds tools in a scripts folder and presents each one through a Streamlit interface.

PRODUCT SCOPE

What was built

  • 01Automatic discovery of scripts added to the tools folder.
  • 02Sprite processing and image background removal.
  • 03Tool execution and preparation of files for ZIP export.

IMPLEMENTATION

Contribution and decisions

  • Each tool stays isolated and can be added as a Python script.
  • Streamlit provides the web interface; Pillow and ONNX Runtime support image tasks.
  • The README describes a local setup and an extensible launcher without per-tool configuration.

SOLUTION LOGIC

Solution flow

  1. 01Add a script→
  2. 02Discover the tool→
  3. 03Run it in the browser→
  4. 04Export the result
LEARNING

A small convention for extensions turns individual scripts into a catalog other people can use.
